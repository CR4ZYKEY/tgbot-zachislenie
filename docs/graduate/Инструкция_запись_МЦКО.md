## Как записаться на пробный экзамен в МЦКО

1. Создайте личный кабинет на **cnd.mcko.ru**. Кнопка «Вход» в правом верхнем углу → «Создать учетную запись».
   Это отдельный сайт Центра независимых диагностик — не общий mcko.ru.
2. Откройте раздел «Индивидуальная диагностика» и нажмите «Записаться на диагностику».
3. Введите данные ученика. ФИО — точно как в документе, удостоверяющем личность.
   В поле «Образовательное учреждение» ученикам школ ЦПСО выберите «ДОО (не Москва)».
4. Выберите тип диагностики: «Диагностика ОГЭ/ЕГЭ» — очно, «Онлайн-диагностика в формате ОГЭ/ЕГЭ» — из дома.
   Перечень предметов для онлайна ограничен, иностранные языки — только очно.
5. Выберите класс и предмет — класс тот, за который нужна диагностика.
6. Выберите центр и время: конкретный ЦНД с датой — или «ЦНД Онлайн».
7. Оплатите в течение 72 часов в личном кабинете, раздел «Мои диагностики».
   По истечении срока заявка аннулируется — в кабинете идёт таймер.

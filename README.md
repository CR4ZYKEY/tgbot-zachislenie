### Напоминания

Экран-«ожидание» сам объявляет, когда и чем напомнить (`reminders` в
[scenario/scenario.yaml](scenario/scenario.yaml)) — код про конкретные сроки
и экраны ничего не знает. Первым это использует `e2_2_sent`: родитель
подтвердил отправку документов, дальше бот через сутки и через двое просит
проверить почту, а как только родитель ответил «письмо пришло» — оставшиеся
напоминания снимаются сами.

Проверить цепочку целиком, не ожидая двое суток:

```bash
REMINDER_TEST_MINUTES=2 npm run worker:dev   # сутки сжимаются до 2 минут
```

В этом режиме тихие часы не действуют — иначе вечерний прогон молча уехал бы
на утро. В проде переменная не задаётся.

## Команды

```bash
npm install
docker compose up -d postgres   # если есть docker-compose.yml — иначе локальный Postgres
npx prisma migrate dev
npm run scenario:check
npm run start:dev               # бот
npm run worker:dev              # воркер, отдельный процесс
```

Перед первым запуском скопируйте `.env.example` в `.env` и укажите
тестовый токен из @BotFather (не боевой — см. CLAUDE.md, раздел «Чего не делать»).
